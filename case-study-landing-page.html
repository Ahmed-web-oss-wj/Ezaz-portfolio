Project 03

Amber & Oak — Landing Page

A full client-style landing page for a fictional coffee brand — built to practice the kind of end-to-end page structure a real client project demands.

View Live Demo View Code
Role
Solo Developer
Stack
HTML · CSS
Type
Client-style Site
The Problem

App projects don't prove design sense.

Expense trackers and search tools prove logic skills, but freelance work is mostly landing pages and marketing sites — and those live or die on layout, type, and visual hierarchy, not functionality. I wanted a project that demonstrated I could take a brand brief and turn it into a full, cohesive page.

The Approach

Design a brand, then build its site.

I invented a fictional café — Amber & Oak — and designed a full visual identity around it: a warm, editorial palette, a serif display font paired with a clean sans-serif for structure, and a tone of voice to match. The page follows a real client-site structure: hero, story, menu, testimonials, and a closing call-to-action, each section built as its own responsive block.

The goal was restraint — resisting the urge to add every trendy effect, and instead making sure spacing, type scale, and color did the actual work of making the page feel considered.

Key Features
  • 01 Full page structure: hero, story, menu, testimonials, CTA
  • 02 Custom color palette and type pairing built for the brand
  • 03 Fully responsive across mobile, tablet, and desktop
  • 04 Anchor-linked navigation for smooth in-page scrolling
Tech Stack
HTML5 CSS3 (Grid & Flexbox) Responsive Design Custom Typography
What I Learned

Building a full brand site — even a fictional one — is a different skill from building a functional tool. It forced me to make deliberate decisions about type pairing, spacing rhythm, and color instead of defaulting to whatever looked "fine." That discipline is exactly what client work demands, and it's the muscle this project was built to train.
