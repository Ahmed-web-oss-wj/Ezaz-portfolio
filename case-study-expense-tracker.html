Project 01

Expense Tracker

A lightweight personal finance tool built to answer one simple question at a glance: where is my money actually going?

View Live Demo View Code
Role
Solo Developer
Stack
HTML · CSS · JS
Type
Personal Tool
The Problem

Small expenses are easy to lose track of.

Most people don't overspend on one big purchase — they lose track through a dozen small ones. I wanted a tool that made logging a transaction fast enough that I'd actually use it daily, without needing an app store download or a login.

The Approach

Keep it fast, keep it honest.

I built this as a single-page tool with no build step and no dependencies — just HTML, CSS, and vanilla JavaScript. The entire interaction is: type a description, enter an amount, pick income or expense, hit add. The balance, income, and expense totals recalculate instantly using plain DOM updates, no framework needed.

The hardest part wasn't the logic — it was resisting the urge to over-engineer a simple tool. Keeping the code readable and the UI honest about what it does (and doesn't do — like not persisting data) mattered more than adding features nobody asked for.

Key Features
  • 01 Add income or expense entries with live category tagging
  • 02 Real-time balance, income, and expense totals
  • 03 One-click delete for any transaction
  • 04 Fully responsive layout, works cleanly on mobile
Tech Stack
HTML5 CSS3 (Grid & Flexbox) Vanilla JavaScript DOM Manipulation
What I Learned

This project reinforced how much can be done with plain JavaScript before reaching for a framework — array methods like filter and reduce did all the heavy lifting for the totals. It also taught me to think about state management early, even in a small app: keeping transactions in a single array made every other part of the UI easy to keep in sync.
